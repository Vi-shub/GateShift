# Traefik ingress-nginx fixtures

Positive Ingress fixtures adapted from
[traefik/traefik](https://github.com/traefik/traefik)
`pkg/provider/kubernetes/ingress-nginx/fixtures/ingresses/`.

These exercise single-annotation and small combinations (rate limit, CORS,
rewrite, redirects, SSL passthrough, canary pairs, snippets, proxy tuning).
